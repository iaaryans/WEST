WEST Moodspace category/shelf crash hardening

Issue: The online mood/genre catalog includes seasonal categories such as
"Hanukkah". Their browse responses can contain repeated sections with no
heading. The prior Moodspace UI used `shelf/${it.title}` as the LazyColumn
key. Two unnamed shelves both became `shelf/Playlists`, which is an illegal
duplicate LazyColumn key and can crash the Android process.

Source changes:
- MoodspaceScreen now identifies a selected category using its unique browse
  endpoint and params instead of its display title.
- Row, shelf, and playlist LazyColumn/LazyRow keys use unique scoped indices;
  duplicate labels and cross-section playlist IDs no longer collide.
- MoodspaceSafety validates and bounds returned playlist sections, rejects
  unsupported/empty navigation endpoints and preserves supported playlist,
  artist, and album destinations.
- HomeScreen also routes Moodspace selections through the validated mapping.
- MoodExploreParser limits excessively large/unexpected section and artwork
  traversal while retaining the upstream category catalog.
- Exceptions while loading a category, songs, or artwork are logged with tag
  WEST_Moodspace and fall back to normal song discovery.

Coverage:
- Added unit tests for a "Hanukkah" sample with repeated unnamed shelves,
  unique Compose lazy keys, special-category browse IDs, malformed playlist
  entries, deduplication, and fallback behavior.
- Standalone Kotlin smoke tests for category identity and shelf routing passed.
- No existing source files, Git objects, Search regression fixes, WEST
  Intelligence or Hybrid Smart Queue functionality were removed.
- README structure is unchanged.

Important validation limit:
A crash report/logcat was not provided, so the exact device exception is not
confirmed. Android compilation and emulator validation remain unverified because
the Gradle 7.4 distribution and Android SDK are unavailable in this workspace.

Device regression steps:
1. Launch WEST and visit Moodspace; scroll the full genre grid.
2. Open Hanukkah or any category with several playlist rows, including
   repeated headings; verify the app stays open and playlists/songs load.
3. Return to the grid, switch between Moodspace and Home several times.
4. Test Play all and individual tracks, Next/Previous, offline fallback,
   category refresh, saved Search history, and keyboard Search.
5. Capture `adb logcat -s WEST_Moodspace AndroidRuntime` if a crash persists.
