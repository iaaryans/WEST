The WEST Home redesign follows the reference's layout concepts: a prominent
Listen Now header, portrait artwork-backed Top Picks cards, four songs per
horizontally paged Recents column, and horizontal album/artist/playlist shelves.
The implementation is written against WEST's existing Compose components,
Innertube search, Media3 queue controller and WEST Intelligence profile.
BitChord code must not be assumed interchangeable with WEST modules.

WEST-specific changes: original WEST branding; Moodspace remains ONLY its own
bottom-navigation tab, not a home shortcut; songs start Hybrid Smart Queue;
Home retains Insights, Settings, timed mix, Spotify import and offline shortcuts.
